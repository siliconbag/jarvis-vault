# Jarvis Vault - репозиторий тренинга «Создаем Джарвиса» (30-31.07.2026)

Файл для организаторов (КУ / АС / ИИв). Участникам он не нужен.

## Что это

Один репозиторий, две роли:
1. **Преднастроенный Vault участника** - каждый клонирует его себе в С1-С2 как основу второго мозга (структура вики + уроки внутри).
2. **MD-хаб тренинга** - те же файлы раздаются HTTP-статикой на нашем домене. Агент участника (OpenCode / Claude Code / любой) сам забирает нужный файл по URL. Никаких презентаций с инструкциями и рассылок списками.

Точка перехода «ноль слайдов»: до запуска агента участник получает от бота две ссылки (скачать OpenCode, вставить ключ). Дальше первая команда: «сходи на https://raw.githubusercontent.com/siliconbag/jarvis-vault/main/index.md и расскажи, что там». Все остальное - только через хаб.

## Публикация (тудушка КУ)

- Канон: приватный или публичный git-репо (секретов внутри нет - можно публичный).
- Раздача: статика на ai.altget.ru/vault/ или поддомен (РФ-хостинг, работает без VPN). Синк с репо: git pull по крону или хук.
- Временный BASE_URL уже подставлен: raw.githubusercontent.com/siliconbag/jarvis-vault/main (рабочий прото-хаб). При переезде на домен КУ заменить на финальный URL во всех файлах.
- Проверить с РФ-IP и с мобильного интернета: файлы отдаются, агенты их читают.

## Правила репозитория

1. Имена файлов - латиница/транслит (URL диктуются голосом со сцены, кириллица в URL ломается в энкодинг).
2. Один файл = одна тема. Не портянки: агент забирает только нужное, токены участника ограничены.
3. У каждого файла frontmatter с `description` (одна строка) - из них собирается index.md.
4. Секретов нет: ключи OpenRouter, приглашения, пароль Wi-Fi - только через бота или экран в зале.
5. Правки в перерывах: поправил файл -> push -> статика обновилась -> у всех агентов свежее.
6. Уроки пишутся ДЛЯ АГЕНТА участника (он ведет человека), формат - shablony/shablon-uroka.md.
