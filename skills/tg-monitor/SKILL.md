# TG-Monitor: чужие каналы под присмотром

Ты следишь за списком публичных Telegram-каналов участника (конкуренты, ниша, отраслевые СМИ) и приносишь дайджест: что вышло нового, что залетело, о чем пишут. Без Telegram-API, без логина - через открытое веб-превью.

## Как это работает (главный трюк)
У каждого публичного канала есть веб-версия: `https://t.me/s/<имя_канала>` (буква s в пути!). Это чистая HTML-страница с последними ~20 постами - открывается без авторизации, легко читается. Глубже в историю: `https://t.me/s/<имя>?before=<id_поста>`.

Имя канала нормализуй: убери @, из ссылки t.me/xxx возьми xxx.

## Что где лежит в HTML (проверено боевым скрейпером)
- Пост: блок `tgme_widget_message` с атрибутом `data-post="канал/id"` - отсюда id.
- Текст: `tgme_widget_message_text`.
- Дата: внутри `a.tgme_widget_message_date` элемент `time` с атрибутом `datetime`.
- Просмотры: `tgme_widget_message_views`. Реакции: суммируй числа в `tgme_reaction`. Комментарии: `tgme_widget_message_replies` -> `counter_value`.
- Числа вида `1.2K` / `3.5M` переводи в полные (K=тысячи, M=миллионы).
- Шапка канала: название `tgme_channel_info_header_title`, описание `tgme_channel_info_description`, подписчики `tgme_channel_info_counter` -> `counter_value`.
- Ссылка на пост для дайджеста: `https://t.me/<канал>/<id>`.

## Шаг 1. Настрой список
Спроси участника: за какими каналами следить (3-10 для старта) и зачем (конкуренты / идеи контента / новости ниши). Сохрани список в базу: `viki/monitoring/kanaly.md` - канал, зачем следим, last_seen_id.

## Шаг 2. Сбор
Для каждого канала забери страницу t.me/s/, распарси посты новее last_seen_id. Пауза между запросами - секунда, не молоти. Обнови last_seen_id. Первый прогон: возьми только последнюю страницу (~20 постов), не выкачивай историю.

Если t.me не открывается с текущей сети: сделай то же самое со своего VPS (если ты там живешь - проблема не возникнет) или скажи участнику включить VPN. Запасной путь - вытащить страницу через Exa.

## Шаг 3. Дайджест
Собери в одно сообщение/страницу:
- **Новое** (со ссылками): 1 строка на пост - суть, просмотры.
- **Залетело**: посты с просмотрами/реакциями заметно выше обычного для этого канала - разбери, почему (тема? формат? хук?).
- **Темы недели**: 2-3 предложения, о чем пишет ниша.
Сохрани дайджест в `viki/monitoring/` с датой, участнику - краткую версию.

## Шаг 4. Регулярность (по желанию)
«Каждое утро в 9 собирай дайджест по моим каналам» - поставь себе расписание. Дайджест можно вклеивать в утреннюю сводку/дашборд.

## Что участник получает (проговори)
- Конкуренты: видно их запуски, акции и цены без ручного листания.
- Контент: чужие залетевшие темы = идеи для своих постов.
- Ниша: новости отрасли приходят выжимкой, а не лентой.

## Ограничения (честно)
- Только публичные каналы. Приватные и каналы с ограничениями через t.me/s/ не отдаются.
- Веб-превью показывает не все типы постов (опросы, некоторые медиа) - текстовые посты видны надежно.
- Это чтение открытых страниц, тех же, что видит любой браузер. Не выдавай себя за подписчика и не перегружай запросами.
