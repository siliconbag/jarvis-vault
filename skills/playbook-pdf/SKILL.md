# Playbook-PDF: из лонгрида в фирменный гайд

Ты превращаешь чужой англоязычный первоисточник в русский PDF-плейбук, который не стыдно раздавать: перевод без машинного привкуса, словарик терминов, аккуратная верстка. Плюс пост-подводку для соцсетей. Веди участника по шагам, тяжелую работу делай сам.

## Шаг 0. Проверь материал
Хороший кандидат: ОДИН свежий авторский первоисточник с практикой (гайд, разбор, методика). Плохой: подборки ссылок, новости, компиляции - из них плейбук не живет. Если материал слабый - скажи честно и предложи поискать сильнее (есть Exa).

## Шаг 1. Забери исходник
Участник вставляет текст целиком или дает ссылку. Сохрани оригинал отдельным файлом в базу (исходники не редактируем). Зафиксируй: автор, название, ссылка на оригинал.

## Шаг 2. Переведи по правилам
- Структура 1:1: заголовки, списки, таблицы, порядок - как в оригинале.
- НЕ переводить: код и code fence, названия продуктов, идентификаторы, URL, никнеймы.
- Числа, единицы, модальности (can/must/should) - переносить точно.
- Термины - по глоссарию `glossary.json` рядом с этим скиллом: если термин там есть, используй только его перевод. Новый устойчивый термин - добавь в `glossary_candidates.json` (термин, перевод, короткое определение, где встретился) и используй выбранный вариант последовательно по всему тексту.

## Шаг 3. Очисти от машинного привкуса
Пройди перевод редактором. Убрать:
- длинные тире (заменяй дефисом или перестраивай фразу), букву "ё" (всегда "е");
- конструкции "это не просто X, это Y", "не только... но и" (негативные параллелизмы);
- тройки-перечисления ради ритма (rule of three), "в мире, где...", "стоит отметить";
- вздутую символичность ("подчеркивает", "свидетельствует", "демонстрирует приверженность");
- канцелярит и кальки ("данный", "осуществлять", "является ключевым");
- одинаковые начала абзацев, обороты-связки в каждом предложении ("более того", "кроме того").
Тон: нейтральный технический, живой русский. Смысл не менять, сокращать можно.

## Шаг 4. Словарик терминов
В конец документа - раздел "Словарик": термины из глоссария, которые встретились в тексте, с короткими определениями на русском. Отсортируй по алфавиту.

## Шаг 5. Сверстай
Собери HTML-файл с инлайн-CSS (самодостаточный, без внешних зависимостей кроме шрифта):
- титульный блок: название плейбука, автор оригинала и ссылка, строка "Перевод и адаптация: <имя участника + его канал>", дата;
- оглавление с якорями по заголовкам;
- шрифт: PT Serif (Google Fonts) с фолбэком Georgia/serif; моноширинный для кода; A4-геометрия через @page и @media print (поля ~25мм, интерлиньяж 1.15);
- код-блоки с фоном и рамкой, таблицы с booktabs-стилем (тонкие горизонтальные линии), без полосатости;
- футер страницы с названием и номером (счетчики @page).
Открой файл в браузере -> Печать -> "Сохранить как PDF". Это дефолтный путь, работает у всех.
Продвинутый путь (по желанию, если можешь ставить пакеты): pandoc + tectonic дают типографский PDF - предложи, но не настаивай.

## Шаг 6. Проверь перед выдачей
- Заголовки и структура совпадают с оригиналом; ни один code fence не переведен.
- Кириллица в коде и подписях не съехала; ссылки кликабельны.
- Словарик на месте; титул со ссылкой на оригинал (это обязательная этика: всегда указываем автора).

## Шаг 7. Пост-подводка (механика продвижения)
Спроси, куда участник будет постить (Threads/Facebook/Telegram/LinkedIn), и собери:
- 2-4 абзаца подводки: почему этот материал стоит внимания, 1-2 конкретные находки из него, без пересказа целиком;
- призыв: сам плейбук (PDF) - в Telegram-канале участника, ссылка;
- подскажи, какие 2-3 разворота PDF красиво выглядят скриншотами.
Схема: пост с тизером и скриншотами в соцсети -> PDF в Telegram -> подписчик приходит за файлом.

## Грабли
- Не выдумывай факты при переводе: непонятное место - спроси или оставь примечание переводчика.
- Большой текст (>3000 слов) - переводи частями, потом один проход шага 3 по всему тексту целиком.
- Глоссарий обновляй только добавлением: существующие переводы не менять (стабильность терминов важнее вкуса).
