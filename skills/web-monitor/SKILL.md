# Web-Monitor: сайты под присмотром

Ты умеешь превращать чужие сайты в данные для базы участника: разовый сбор, регулярный мониторинг, поиск упоминаний. Принцип: не стреляй из пушки по воробьям - выбирай самый легкий инструмент, который решает задачу.

## Меню инструментов (проверенный топ, ставишь по необходимости)

| Задача | Инструмент | Что это |
|---|---|---|
| Страница/сайт -> чистый markdown для базы | **crawl4ai** (github.com/unclecode/crawl4ai) | Python, ставится pip, создан для LLM. Дефолтный выбор |
| Любой файл или страница -> markdown (PDF, Office, картинки) | **markitdown** (github.com/microsoft/markitdown) | Конвертер Microsoft, pip |
| Сайт с JavaScript, кликами, формами | **browser-use** (github.com/browser-use/browser-use) | Агент управляет браузером как человек. Тяжелый - только если легкие не справились |
| Целый сайт постранично, JS-рендер, структурные данные | **firecrawl** (github.com/firecrawl/firecrawl) | В Hermes есть интеграция-плагин (нужен ключ) либо self-host |
| Однотипные страницы по образцу (каталог, карточки) | **autoscraper** (github.com/alirezamika/autoscraper) | Показываешь пример - он строит шаблон |
| Сайт режет запросы ботов | **curl-impersonate** (github.com/lwthiker/curl-impersonate) | curl с отпечатком реального Chrome |

Начинай с обычного fetch/crawl4ai; браузерные и анти-бот инструменты - только когда простое не сработало.

## Сценарий A. Разовый сбор: «прочитай сайт и положи в базу»
1. Забери страницы (crawl4ai/markitdown) -> чистый markdown.
2. Выжимку в вики со ссылкой на источник и датой; сырье - в raw. Не копируй сайт целиком - извлеки то, зачем пришли (цены, услуги, позиционирование).

## Сценарий B. Регулярно: новости конкурентов
1. Спроси список: 3-10 URL (страницы новостей, блоги, прайсы конкурентов). Сохрани в `viki/monitoring/sajty.md` с отметкой, что важно ловить.
2. При каждом прогоне: забери страницы, сравни с прошлым слепком (храни хеш/выжимку), выдели ЧТО ИЗМЕНИЛОСЬ.
3. Дайджест: новое у каждого конкурента одной строкой + ссылки; изменения цен/офферов - отдельно, это самое ценное.
4. По желанию - расписание: «каждый понедельник в 9». Дайджест стыкуется с утренней сводкой и tg-monitor (телеграм-каналы тем же ритмом).

## Сценарий C. «Что пишут обо мне / о компании»
1. Поиск упоминаний - через Exa (поиск по смыслу, уже подключен): имя, компания, продукт.
2. Свой сайт - прямым обходом (сценарий A): что он реально говорит о продукте и ценах.
3. Итог в базу: страница «как нас видит интернет» с фактами и ссылками. Правило: факт без ссылки - не факт; нашел неточность - участник ее правит у себя на сайте, не в базе.

## Правила
- Читай открытые страницы. Не обходи логины и пейволы, не выдавай себя за пользователя.
- Паузы между запросами (секунда+), не нагружай чужой сайт - тебе нужен дифф, не зеркало.
- Все в базу кладется со ссылкой и датой - иначе через месяц цифре нельзя верить.
- Персональные данные посторонних людей в базу не собирай.
