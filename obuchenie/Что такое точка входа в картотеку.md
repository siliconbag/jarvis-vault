Точка входа в картотеку - это те механики и инструменты, через которые мы начинаем взаимодействовать с нашими записями в базе. 

Самый простой и очевидный способ - это через Файловый менеджер. Панелька слева со списком всех файлов и папок, с помощью которого мы переходим в нужные заметки. Но этот способ не единственный, и точно не самый быстрой. 

Я выделю, помимо Файлового менеджера, следующие точки входа:

- Поиск. Как уже неоднократно упоминал - рекомендую использовать для этих целей [[Omnisearch]]
- Закладки. Сильно недооценённый инструмент. Встроенный плагин позволяет делать ссылки на самые важные заметки, заранее настроенный граф,  и что для меня было совсем не очевидно - на папки внутри нашей картотеки. Попробуйте. 
- Граф
- Поисковые заметки
- Запросы [[Что такое Dataview и для чего он нужен|Dataview]], например список последних измененных заметок
- Календарь - для быстрого доступа к заметкам за определенные даты
- Панелька тегов. Тоже может быть полезной штукой
- Индексные заметки. Те самые MoC< ToC, zero-links
- Блуждающий режим с помощью плагина Improved Random Note
