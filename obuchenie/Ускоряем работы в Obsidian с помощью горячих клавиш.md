### Настройка
![[Hotkeys.png]]
В окне настроек вы видите все возможные команды, на которые можно назначить комбинацию клавиш. Если нажать на иконку клавиатуры в поле Фильтр и зажать комбинацию, например `Cmd+T`, Obsidian покажет вам команду, на которую назначена данная комбинация

### Рекомендации
Следите за тем, что делаете, какие команды вызываете чаще всего в процессе работы с базой. И если замечаете, что слишком часто тыкаете в какие-то меню, или вызываете команду через промежуточный этап Палитры команд `Cmd+P`, то это верный признак - на команду надо вешать комбинацию горячих клавиш. 

! <font color="#ff0000">Я гарантирую вам</font>, что если вы внедрите в работу хотя бы 50% от предложенных сочетаний клавиш, то в работе с текстом вы сэкономите себе часы времени на то, чтобы заняться чем-то более приятным. Если мои рекомендации не сработают, я верну вам деньги, которые вы заплатили за доступ к этому хранилищу 🤝

### Мои горячие клавищи
Список ниже - это уже предуставленные в данном хранилище комбинации. Некоторые из них могут совпадать со значениями по умолчания (комбинации, которые идут в Obsidian из коробки). Некоторые я переназначал под себя, т.к. меня не устроили дефолтные значения. 

<font color="#ff0000">**Disclaimer**</font> касательно обозначений клавиш. Я работаю в двух операционных системах (Windows и MacOS) попеременно, и уже на автомате переключаюсь мысленно на нужную раскладку. Ниже комбинации, которые оформлены под MacOS, например Opt - это Option, а Cmd - Command. 

**Условные обозначения:**
⌘ - Command, он же Control (если не указано иное)
⌥ - Option, он же Alt
⇧ - Shift

Если вы работаете под Windows - все просто. Opt у вас изменится на Alt, а Cmd - на Control. В остальном - комбинации идентичны. 

`⌘ + O` - окно стандартного поиска. Рекомендую переназначить эту комбинацию на поиск через [[Omnisearch]], либо вообще ее не использовать (в описании Omnisearch объяснил - почему)
`⌘ + ⌥ + ←`- вернуться назад (к предыдущей заметке, открытой в этой же вкладке)

`⌘ + B` - Включает режим "жирного" текста. Если вы выделили какой-то текст в режиме редактирования - нажатие комбинации сделает его жирным (или наоборот - обычным, если до этого он уже был жирным)

`⌘ + I` - то же самое что и предыдущий пункт, только для *курсива*

`⌘ + K` - вставить ссылку на внешний ресурс

`⌥ + O` - Поиск по хранилищу через плагин [[Omnisearch]] 

`⇧ + ⌥ + C ` - Вставить шаблон с заготовкой под Callout. Реализовано через [[Templater]]

`⌘ + G` - Показать глобальный граф

`⌥ + X` - Добавить внутреннюю ссылку. Выделяете какое-то слово или сочетание, которое хотите сделать ссылкой на заметку (хоть созданную, хоть новую), и выделенное вами будет "обрамлено" в ``

`⌘ + ;` - Добавить свойство к заметке

`⌘ + W` - Закрыть текущую вкладку

`⌘ + ⇧ + D` - Переключиться между светлым/темным режимом

`⌘ + ,` - Открыть окно настроек Obsidian

`⌘ + Enter` - открыть ссылку под курсором

`⌘ + ⌥ + ⇧ + Enter` -  открыть ссылку под курсором в новом окне

`⌘ + ⌥ + Enter` -  открыть ссылку под курсором в области справа

`⌘ + P` - Открыть палитру команд

`⌘ + R` - Перезагрузить приложение

`⌘ + ⌥ + →` - Перейти вперед

`⌘ + 9` - Перейти на последнюю вкладку

`Ctrl + Tab` - перейти на следующую вкладку (работает и в MacOS и в Windows)

`Ctrl + ⇧ + Tab` - перейти на предыдущую вкладку (работает и в MacOS и в Windows)

В этих двух командах выше Control это именно Control, а не Command в MacOS

`⌥ + Enter` - перейти по ссылке под курсором

`⌘ + L` - переключить состояние флажка

`⌘ + E` - Переключение между режимами просмотра и редактирования

`⌘ + M` - Переместить файл в другую папку

`⌘ + F` - Поиск внутри текущей заметки

`⌘ + ⌥ + F`- Поиск и замена в текущем файле

`⌘ + ⇧ + F` - Поиск во всех файлах

🔥 `Ctrl + ⌥ + ↑` - двинуть текущую строку вверх

🔥 `Ctrl + ⌥ + ↓` - двинуть текущую строку вниз

- ! Эти две команды могут в разы ускорить вашу работу с текстом

`F2` - редактировать заголовок. Тоже огонь, увидел только сейчас, когда составлял этот список. Век живи, век учись 🙂

`⌘ + ⌥ + L` - Свернуть/развернуть левую панель

`⌘ + ⌥ + R` - Свернуть/развернуть правую панель

`⌥ + S` - Сложить или разложить вкладки (перейти в вертикальный режим вкладок)

`⌥ + T` - Сменить тему

`⌘ + ⇧ + N` - Создать новую заметку в области справа. Тоже крутая штука

`⌘ + N` - Создать новую заметку

`⌘ + T` - вставить [[Шаблоны заметок|Шаблон]]

`⌘ + ⇧ + F11` - Перейти в полноэкранный режим

`⌘ + F11` - Перейти в режим фокусировки (скрываются все элементы интерфейса кроме окна с текстом текущей открытой заметки)

- & Две команды выше работают через плагин [[Editing toolbar]]

`⌘ + ⇧ + J` - Установить иконку на текущую заметку

- ! Ниже сочетания для плагина Outliner, т.е. для работы со списками
`⌘ + ↑` - Свернуть список
`⌘ + ↓` - Развернуть список
🔥 `⌘ + ⇧ + →` - двинуть элемент списка (и всего его подпункты) "вглубь"
🔥 `⌘ + ⇧ + ↓` - двинуть элемент списка (и все его содержимое) на строчку вниз
🔥 `⌘ + ⇧ + ↑` - двинуть элемент списка (и все его содержимое) на строчку вверх
🔥 `⌘ + ⇧ + ←` - двинуть элемент списка (и всего его подпункты) влево ^650429

`⌥ + ⇧ + V` - Вставить текст из буфера с помощью Paste mode ^503044

`Ctrl + ⇧ + R` - Создать лист рандомных вопросов для дневника с помощью Random Structural Diary

`Ctrl + 4`- Текущую строку превращает в заголовок четвертого уровня
`Ctrl + 5`- Текущую строку превращает в заголовок пятого уровня
`Ctrl + 6`- Текущую строку превращает в заголовок шестого уровня
`⌥ + ⇧ + ~` - символ бэктика

`⌥ + Ъ (русский твёрдый знак)` - Закрывающая квадратная скобка ]
`⌥ + ⇧ + Х (русская хэ)` - Открывающая фигурная скобка {

`⌥ + 2` - символ @
`⌥ + 3` - символ # 
`⌥ + 4` - символ $
`⌥ + 5` - символ %
`⌥ + 6` - символ ^
`⌥ + 7` - символ &
`⌥ + Б` - символ <
`⌥ + Ю` - символ >
`⌥ + ⇧ + \` - символ |
`Ctrl + бэктик` - создает блок кода ^1ad934

`⌘ + ⇧ + S` - включает режим фокусировки, когда активна только текущая строка, а все остальные строки затеняются. Реализовано с помощью плагина Stille

`⌥ + N` - создать новую заметку с помощью [[Templater]]˜

`⌥ + ⇧ + A` - выделите текст и нажмите эту комбинацию. Выделенный текст станет алиасом (псевдонимом) для заметки, которую вы выберите из списка ^828660

`⌥ + ⇧ + K` - выделенный текст становится ссылкой на заметку (новую или уже созданную), а курсор встает на позицию после символа |, предлагая создать алиас/псевдоним.

`⌥ + ⇧ + C` - быстрая вставка шаблона с callout для цитирования
