# Свой Telegram-бот для Джарвиса

Зачем: свой бот = дверь к твоему Hermes с телефона. Диктуешь голосом на ходу - Джарвис слышит, отвечает, раскладывает в базу.

## Шаг 1. Придумай ник бота (с агентом)
Ник должен быть свободен и заканчиваться на bot. Скажи агенту: «я - <кто ты, чем занимаешься>, предложи 10-15 свободных вариантов ника для моего бота». Выбери из списка.

## Шаг 2. Создай бота
1. В Telegram найди @BotFather (официальный, с галочкой).
2. Команда /newbot -> имя бота (любое, видно в шапке) -> ник из шага 1 (если занят - следующий вариант).
3. BotFather пришлет токен (длинная строка с двоеточием). Это ключ от бота.

## Шаг 3. Отдай токен Hermes
Токен вставляем ТОЛЬКО в настройки Hermes, не в чат с агентом. Агент, впиши токен в конфиг Telegram-подключения Hermes и сразу настрой ограничение доступа: бот отвечает только владельцу (allowlist по Telegram-ID участника; узнать свой ID можно у @userinfobot). Перезапусти Hermes.

## Шаг 4. Проверь
Напиши своему боту «привет» с телефона - Джарвис ответил. Отправь голосовуху - он распознает и ответит (транскрипцию делает Hermes; если попросит ключ распознавания - скажи куратору).

**Что участник должен увидеть:** бот в телефоне отвечает текстом на текст и на голос.

Безопасность: токен бота = полный доступ к боту. Никому не пересылай. Без allowlist твоему Джарвису сможет писать кто угодно - allowlist обязателен.
