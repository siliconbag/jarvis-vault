# Свой Telegram-бот для Джарвиса

Зачем: свой бот = дверь к твоему Hermes с телефона. Диктуешь голосом на ходу - Джарвис слышит, отвечает, раскладывает в базу.

## Путь A: автоматически (рекомендуется, ~1 минута)

1. В терминале: `hermes setup gateway`.
2. Стрелкой до **Telegram**, **пробел** (галочка [✓]!), Enter.
3. На «How would you like to create your Telegram bot?» - просто **Enter** (вариант 1, Automatic, уже дефолт).
4. Терминал покажет ссылку (и QR, если установлен пакет qrcode). Ссылка может быть некликабельной - **скопируй ее в браузер**, откроется Telegram.
5. В окне «Создание бота»: впиши **название** (любое человеческое - «Джарвис», свое) и, по желанию, свой **ник** вместо автоматического (поле редактируемое, окончание bot, доступность проверяется на лету; попроси агента предложить 10 свободных вариантов, если хочется красивый).
6. Жми **«Создать»** - терминал сам получит токен, ничего копировать не нужно.

## Путь B: вручную через BotFather

1. В Telegram найди @BotFather (официальный, с галочкой) -> `/newbot` -> имя -> ник (окончание bot; занят - следующий вариант, агент подскажет свободные).
2. BotFather выдаст токен - строка вида `1234567890:AAEhBOwe...` (цифры, двоеточие, буквы).
3. `hermes setup gateway` -> Telegram (пробел + Enter) -> Choice **2** -> вставь токен.
4. Ошибка «Invalid token format» = вставился не тот ключ (OpenRouter и v0 выглядят иначе) - проверь, что копируешь именно токен бота.

Уже есть свои боты? Токен существующего: @BotFather -> `/mybots` -> выбрать -> API Token. Бери только СВОБОДНОГО бота: если его уже использует другой сервис, они будут отбирать сообщения друг у друга.

## Ограничь доступ
Бот должен отвечать только тебе: allowlist по твоему Telegram-ID (узнать - напиши @userinfobot). В Automatic-пути визард обычно настраивает это сам; проверь у агента: «кто имеет доступ к моему боту?»

## Запусти связку
`hermes gateway` - и оставь это окно терминала открытым: закрыл окно - бот уснул. (На VPS гейтвей работает сам, без открытых окон - еще один аргумент за завтрашний переезд.)

## Проверка
Напиши своему боту «привет» с телефона - Джарвис ответил. Отправь голосовуху - распознает и ответит (если нет - шаг 2 «Доводки» в ustanovka/hermes.md: Speech-to-Text).

Безопасность: токен бота = полный доступ к боту. Никому не пересылай, в чат с агентом не вставляй - только в настройки Hermes (или отдай визарду).
