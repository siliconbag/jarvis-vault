# Скилл «Персональный дашборд»

Что дает: говоришь Джарвису «собери мне дашборд» - через ~2 минуты у тебя ссылка на живой дашборд с твоими задачами, встречами и привычками, плюс сам файл. Генерирует v0 (генератор интерфейсов Vercel) - твои токены OpenRouter не тратятся.

## Установка (делает агент)
Агент, поставь скилл участнику:
1. Создай папку `dashboard-v0` в `~/.hermes/skills/` и забери туда `skills/dashboard-v0/SKILL.md` из хаба (raw-ссылка, база `https://raw.githubusercontent.com/siliconbag/jarvis-vault/main/`).
2. Ключ v0 пришел участнику от бота тренинга. Сохрани его в `~/.hermes/.env` строкой `V0_API_KEY=...`, права файла 600. Ключ общий на группу: не в Vault, не в git, не в чат - только этот файл.
3. Перезапусти Hermes и проверь: «какие скиллы у тебя есть?» - в списке dashboard-v0.

## Проба
Скажи: «собери мне дашборд, пока на мок-данных». Дождись ссылки (2 минуты - норма). Настоящий - после подключения источников в слоте 2.1.

## Правила общего баланса
Ключ один на всех, баланс группы. Генерация - только когда сам попросил; правки дашборда - словами «поправь...» (это дешевле, чем генерить заново). После тренинга для регулярного использования заведи свой ключ на v0.app - инструкция появится в хабе.
