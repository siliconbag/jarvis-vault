# Kimi: подписка Kimi Code и ключ для помощника

Второй вариант подписки, рядом с MiniMax. Инструкция без развилок, адреса точные.

---

Агент, ты ведешь участника по этой инструкции. Правила: по одному шагу, после каждого сверяйся с блоком «что участник должен увидеть». Ключ участник вставляет сам, в чат его не отправляй.

## Чем Kimi отличается от MiniMax

Обе подписки решают одну задачу: фиксированная плата вместо счета по факту. Разница практическая:

- **MiniMax Plus, 20 долларов** - дешевле, плюс речь и картинки в том же тарифе.
- **Kimi Code Allegretto, 39 долларов** - дороже, но заметно больше недельная квота и выше лимит одновременных операций. Это про длинные разборы, большие файлы и долгие агентские цепочки.

Берешь одну. Две подписки одновременно новичку не нужны.

## Шаг 1. Регистрация

Открой **https://www.kimi.com/code** и зарегистрируйся: почта, пароль, код из письма.

**Что участник должен увидеть:** аккаунт создан, страница Kimi Code открыта.

## Шаг 2. Выбрать тариф

> [!warning] Сначала переключи на «Ежемесячно»
> Переключатель над тарифами по умолчанию стоит на **Ежегодно**, и цены показаны со скидкой: Allegretto выглядит как 31 доллар. Это цена при оплате года вперед.
> Нажми **Ежемесячно** слева. Цифры сменятся на настоящие месячные.

| Тариф | В месяц | Описание со страницы |
|---|---|---|
| Moderato | 19 долларов | Еженедельно обновляемый лимит, вход с разных устройств |
| **Allegretto** | **39 долларов** | **Большая недельная квота и повышенный лимит одновременных операций. Выбор профессионалов. Наш выбор** |
| Allegro | 99 долларов | Высокие лимиты для интенсивной разработки |
| Vivace | 199 долларов | Максимальный недельный лимит |

Берем **Allegretto за 39 долларов**. Бесплатного тарифа на странице нет, самый дешевый вход - 19 долларов.

Квота недельная и обновляется раз в семь дней. При повышении тарифа деньги за неиспользованное возвращаются пропорционально - это написано прямо на карточках.

**Что участник должен увидеть:** подписка активна, в кабинете виден срок действия.

> [!info] Про оплату из России
> Российской картой напрямую не проходит. Что делают на практике: зарубежная карта, виртуальная карта посредника, купон с маркетплейса.
> **Мы не рекомендуем конкретного посредника и не отвечаем за него.** Не проходит оплата - работай на своем ключе OpenRouter, все то же самое работает и там.

> Разбор способов с проверенными лотами и ценами: `ustanovka/oplata-podpisok.md`.

## Шаг 3. Взять ключ в консоли

Открой **https://www.kimi.com/code** и нажми **Консоль** в правом верхнем углу (прямой адрес - `https://www.kimi.com/code/console`). Раздел с ключами, кнопка создания.

Ключей на аккаунт можно завести не больше пяти. Заведи один и назови понятно, например `hermes-vps`.

Скопируй ключ целиком и положи в менеджер паролей: второй раз не покажут.

> [!warning] Не перепутай с платформой Moonshot
> У той же компании есть отдельная платформа `platform.moonshot.ai` с оплатой по факту за токены. **Ключ оттуда с подпиской Kimi Code не работает** и наоборот. Нам нужна консоль `kimi.com/code/console`.

**Что участник должен увидеть:** ключ скопирован и сохранен вне волта.

## Шаг 4. Адреса сервиса

| Для чего | Адрес |
|---|---|
| Инструменты в стиле Anthropic (Claude Code, Hermes) | `https://api.kimi.com/coding/` |
| Инструменты в стиле OpenAI (OpenCode) | `https://api.kimi.com/coding/v1` |

Идентификатор модели всегда один: **`kimi-for-coding`**. Не название конкретной модели - подписка сама подставляет актуальную.

## Шаг 5. Подключить к помощнику

Агент, открой файл секретов Hermes, участник вставляет ключ руками:

```
nano ~/.hermes/.env
```

Строки:

```
ANTHROPIC_BASE_URL=https://api.kimi.com/coding/
ANTHROPIC_API_KEY=твой_ключ
```

Сохранить `Ctrl+O`, `Enter`, выйти `Ctrl+X`. Дальше:

```
hermes config set model kimi-for-coding
hermes gateway restart
```

Проверка: спроси у помощника «какая у тебя сейчас модель».

**Что участник должен увидеть:** помощник отвечает, ошибок авторизации нет.

## Шаг 6. Подключить к OpenCode

- адрес сервиса `https://api.kimi.com/coding/v1`
- ключ - тот же
- модель `kimi-for-coding`

Ключ от тренинга не удаляй, пусть остается запасным путем.

**Что участник должен увидеть:** ответ на тестовый вопрос приходит.

## Чекпоинт

Четыре «да»:
1. Подписка Allegretto оплачена и активна.
2. Ключ создан в консоли `kimi.com/code/console`.
3. Помощник отвечает на модели `kimi-for-coding`.
4. Старый ключ остался как запасной.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Ошибка авторизации | Ключ взят на `platform.moonshot.ai` вместо консоли Kimi Code. Создай ключ в `kimi.com/code/console` |
| Модель не найдена | Идентификатор должен быть ровно `kimi-for-coding`, без версии и без суффиксов |
| Работало и вдруг перестало | Исчерпана недельная квота тарифа. Она обновляется раз в семь дней; до обновления работай на запасном ключе |
| Кончилась квота на неделю раньше срока | Тяжелые задачи гонятся на подписке, рутина - на дешевой модели. Правило то же, что и везде |
| Не создается больше ключей | Лимит пять ключей на аккаунт. Удали старый в консоли |
| Оплата не проходит | Работай на своем ключе OpenRouter, разберемся отдельно |
