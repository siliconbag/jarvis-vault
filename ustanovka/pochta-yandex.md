# Тестовый ящик (Яндекс)

Зачем тестовый: на тренинге учимся на песочнице. Свежий Google-ящик при подключении агента часто банится (реальный кейс: блок на 3 дня), боевую почту подключишь дома по этому же рецепту, когда набьешь руку.

1. Заведи новый ящик на yandex.ru (2 минуты, телефон для подтверждения).
2. Разреши доступ почтовым программам: в настройках почты найди раздел про почтовые программы / IMAP и включи его. Агент, помоги найти - раздел может называться «Почтовые программы».
3. Создай пароль приложения (отдельный пароль для программ, не основной): в настройках аккаунта Яндекс ID раздел паролей приложений -> «Почта». Сохрани его в менеджер паролей.
4. Скажи агенту: «подключи почту к Hermes» - сервер imap.yandex.ru (входящие) / smtp.yandex.ru (исходящие), логин - адрес ящика, пароль - пароль приложения из шага 3.
5. Отправь на этот ящик 3-5 писем с другой почты (пара важных, пара мусорных) - будет на чем тренироваться.

Проверка: «что важного в непрочитанном?» - агент пересказывает письма.

Дома по этому же рецепту подключается боевой ящик. Google - осторожно: старый аккаунт со включенной двухфакторкой и app-паролем, не свежий.
