# Exa: глаза агента в интернете

## Зачем
Модель знает мир на момент обучения и, когда не знает, **иногда выдумывает**. Exa — поисковик, сделанный для агентов: агент сам формулирует запрос, получает чистый текст страниц и ссылки на источники. Без него ресёрч — это пересказ памяти модели, с ним — работа с фактами.

**Сколько стоит:** при регистрации дают **$20 кредитов** и добавляют **$10 каждый месяц**. Карту привязывать не нужно. $20 — это примерно **2800 поисков**, то есть на интенсив и на месяцы после.

## Шаги

### 1. Регистрация
`exa.ai` → Sign up (можно через Google). Подтверждаешь почту.
**Что должен увидеть:** личный кабинет (dashboard).

### 2. Ключ
`dashboard.exa.ai/api-keys` → Create API key. Скопируй.
**Что должен увидеть:** строка ключа. Она показывается один раз — сразу отдай агенту, не храни в переписке.

### 3. Отдай ключ агенту
Скажи агенту: «подключи Exa, вот ключ» — он сам поставит нужный компонент и запишет ключ в свои настройки.
**Правило:** ключ хранится в настройках/переменных окружения, **не в файлах базы и не в чате**. Если база синхронизируется на GitHub — ключ туда попасть не должен.

### 4. Проверка
Попроси: «найди через Exa, что сегодня писали про <твоя отрасль>, дай три ссылки».
**Что должен увидеть:** свежие результаты **со ссылками**. Нет ссылок — поиск не подключился, агент отвечает по памяти.

## Правила работы
1. **Факт без ссылки — не факт.** Требуй источник; так сразу видно, где агент домыслил.
2. Ресёрч кладём в базу вместе со ссылками и датой — через месяц будет понятно, откуда цифра.
3. Кредиты не бесконечны: точные запросы дешевле, чем «расскажи всё про рынок». Глубокий ресёрч дороже обычного поиска.
4. Кончились кредиты — раз в месяц приходит новые $10; либо пополняешь, либо ждёшь.

## Если что-то не так
- **Ключ не принимается** — проверь, что скопирован целиком, без пробелов; при сомнении создай новый и удали старый.
- **Ищет, но пусто** — переформулируй описанием желаемой страницы («статья, где сравнивают X и Y»), Exa ищет по смыслу, а не по ключевым словам.
- **Не хочешь регистрироваться сейчас** — у Exa есть бесплатный режим без ключа с лимитом ~150 запросов в день; на попробовать хватит, для работы лучше свой ключ.

## Подключение к Hermes

Ключ Exa добавь строкой в файл секретов Hermes `~/.hermes/.env`:

```
EXA_API_KEY=твой_ключ
```

Перезапусти Hermes (и `hermes gateway`, если запущен). Проверка: спроси «найди в интернете свежее про <твоя тема> со ссылками» - ответ должен опираться на живые страницы. Без ключа у Hermes остается встроенный бесплатный поиск DuckDuckGo - работает, но слабее.
