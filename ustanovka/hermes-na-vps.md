# Hermes на сервере: помощник, который работает без ноутбука

> **Предусловие:** сервер готов по `ustanovka/vps.md`.

---

Агент, ты ведешь участника по этой инструкции. Правила:
- Строго по одному шагу, жди подтверждения.
- Команды на сервере выполняй сам, объясняя, что делаешь.
- Ключи и токены вставляй только в защищенную конфигурацию на сервере. В волт, в чат и в файлы их не пиши.
- После каждого шага сверяйся с блоком «что участник должен увидеть».

## Мини-интервью

1. Сервер готов и вход по ключу работает? Если нет - сначала `ustanovka/vps.md`.
2. Ключ доступа к моделям под рукой? Тот же, что стоит на ноутбуке.
3. Волт уже выложен в приватный репозиторий или пока живет только на ноутбуке?

## Что мы делаем и зачем

На ноутбуке помощник умеет отвечать. На сервере он начинает **работать сам**: утром собирает сводку, следит за источниками, выполняет задачи по расписанию, пишет в мессенджер. Ноутбук при этом закрыт.

Переселение состоит из пяти вещей: поставить, дать мозги, дать память, дать личность, дать расписание.

## Шаг 1. Поставить помощника

Войди на сервер под пользователем `agent`, не под главным.

Установка по официальной документации, одной командой:

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

Объясни участнику, что происходит: скачивается официальный установщик и ставит помощника вместе со всем, что ему нужно.

Проверка после установки:

```
hermes doctor
```

Эта команда сама проверяет, все ли на месте, и подсвечивает проблемы.

**Что участник должен увидеть:** `hermes doctor` не показывает красного.

## Шаг 2. Подключить модель

Помощнику нужны мозги: ключ доступа к моделям.

1. Пропиши ключ в защищенную конфигурацию помощника на сервере (переменная окружения или конфиг с правами только для пользователя `agent`).
2. Выбери модель. Правило то же, что на ноутбуке: дешевая на рутину, дорогая на сложное.

**Что участник должен увидеть:** на вопрос «какая у тебя сейчас модель» помощник отвечает названием.

> [!warning] Про расход на сервере
> Помощник на сервере работает **сам, по расписанию, без вас**. Это значит, что и деньги он тратит без вас. Пока не убедились, что все настроено, ставьте лимит на ключе и не назначайте задачи чаще одного раза в день. Известны случаи, когда настройки по умолчанию за месяц набивали счет в сотни долларов.

## Шаг 3. Дать доступ к волту

Здесь помощник получает вашу память. Волт с ноутбука попадает на сервер через приватный репозиторий.

1. Убедись, что волт участника выложен в **приватный** репозиторий. Публичный - нельзя: там его заметки о людях и бизнесе.
2. Склонируй репозиторий в рабочую папку помощника на сервере.
3. Настрой регулярную синхронизацию: помощник забирает изменения с ноутбука и отдает свои.
4. Проверь, что в репозиторий не уходят секреты, тяжелые файлы и персональные данные: за это отвечает файл `.gitignore`.

**Что участник должен увидеть:** на сервере в папке помощника лежат его заметки.

> [!warning] Что не синхронизируем
> Ключи и пароли, базы с персональными данными, тяжелые медиафайлы. Волт на сервере - это рабочая копия знаний, а не полное зеркало ноутбука.

## Шаг 4. Личность и память

1. Дай помощнику прочитать `AGENTS.md` и профиль из волта - он узнает правила и владельца.
2. Проверь, что файл памяти подключен: туда помощник пишет выводы между сессиями. Без него каждый запуск начинается с нуля.

**Что участник должен увидеть:** на вопрос «кто я и по каким правилам ты работаешь» помощник отвечает фактами из волта, а не общими словами.

## Шаг 5. Связь с телефоном

Чтобы помощник был доступен не только через терминал, подключи мессенджер по инструкции `ustanovka/tg-bot.md`. Токен бота идет в защищенную конфигурацию на сервере, не в переписку.

**Что участник должен увидеть:** написал боту с телефона - помощник ответил, ноутбук при этом закрыт.

## Шаг 6. Первая задача по расписанию

Начни с одной простой и дешевой задачи, а не с пяти сразу. Например: каждое утро в 9:00 собрать короткую сводку и прислать в мессенджер.

**Что участник должен увидеть:** задача записалась и видно, когда она сработает. Настоящая проверка будет завтра утром - это и есть домашнее задание.

## Чекпоинт

Четыре «да»:
1. Помощник на сервере запускается и отвечает.
2. Он видит волт.
3. Он отвечает в мессенджер при закрытом ноутбуке.
4. Одна задача по расписанию поставлена.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Установщик падает | Проверь версию системы и что все обновления встали. Перезайди под `agent`, не под главным пользователем |
| Команда не найдена после установки | Открой новую сессию терминала: путь к программе подхватывается при входе |
| Помощник не отвечает | Сначала `hermes doctor`, он подсветит проблему. Дальше проверяй ключ и баланс |
| Не видит волт | Репозиторий склонирован не в ту папку либо не настроены права для пользователя `agent` |
| Сжигает деньги | Останови задачи по расписанию, поставь дешевую модель, поставь лимит на ключе. Потом разбирайся |
| Ноутбук и сервер разошлись | Синхронизация не отработала. Проверь, что помощник и забирает, и отдает изменения |

## Что делать, если сервера нет

Все то же самое работает на ноутбуке, кроме одного: задачи по расписанию выполняются, только когда он включен. Для большинства участников этого достаточно. Сервер - шаг для тех, кому нужна автоматика без участия.
