# GitHub: склад версий твоего мозга

По-простому: GitHub - это облачный склад папок с файлами, который помнит каждую версию каждого файла. Оттуда ты забираешь наш Vault, туда же (в свой приватный склад) можешь класть копию своего - ничего не потеряется, история правок вечная.

Зачем тебе:
1. Забрать преднастроенный Vault тренинга (одной командой агента).
2. Резервная копия твоего второго мозга с историей версий и доступ помощника с сервера к твоей базе (ustanovka/volt-cherez-github.md).
3. Агент умеет искать там готовые решения и инструменты.

## Шаг 1. Завести аккаунт

Открой github.com, кнопка **Sign up**. Дальше по порядку:

1. **Почта.** Любая рабочая, к которой есть доступ прямо сейчас - на нее придет код.
2. **Пароль.** Не короче восьми символов, с цифрой. Сразу сохрани в менеджер паролей, а не в заметку.
3. **Ник (username).** Только латиница, цифры и дефис. Короткие давно заняты: сразу бери фамилию с цифрами, например `ivanov-2026`. Ник виден публично, но менять его потом можно.
4. **Рассылки** - можно отказаться, ответ `n`.
5. **Проверка «я не робот».** Иногда простая галочка, иногда мини-головоломка с картинками. Если не проходит - обнови страницу и попробуй снова.
6. **Код из письма.** Шесть цифр, приходит в течение минуты. Нет письма - проверь спам.

**Что участник должен увидеть:** открылась главная страница GitHub с твоим ником в правом верхнем углу.

> [!warning] Если просят номер телефона
> Так бывает при регистрации из некоторых сетей. Варианты по порядку: попробуй с мобильного интернета вместо зала, либо зарегистрируйся позже дома. **На тренинге аккаунт GitHub не блокирует ничего** - волт можно забрать и без него, а резервную копию настроишь завтра.

## Шаг 2. Поставить git

Агент, поставь git на машину участника сам, официальным способом под его ОС, и проверь командой `git --version`. Участнику объясни одной фразой: git - это программа, которая умеет запоминать версии файлов, ей пользуется агент, не ты.

**Что участник должен увидеть:** в ответ на проверку появился номер версии, например `git version 2.4x.x`.

## Шаг 3. И все

Клонирование, коммиты и синхронизацию делает агент. Слова `commit` и `push` запоминать не нужно.

**Что участник должен увидеть:** ничего больше делать не надо, идем дальше по уроку.
