# GitHub: склад версий твоего мозга

По-простому: GitHub - это облачный склад папок с файлами, который помнит каждую версию каждого файла. Оттуда ты забираешь наш Vault, туда же (в свой приватный склад) можешь класть копию своего - ничего не потеряется, история правок вечная.

Зачем тебе:
1. Забрать преднастроенный Vault тренинга (одной командой агента).
2. Резервная копия твоего второго мозга с историей версий (ustanovka/sinhronizaciya-volta.md).
3. Агент умеет искать там готовые решения и инструменты.

Шаги:
1. Заведи аккаунт на github.com (почта, пароль, подтверждение). Ник - латиницей, попроще.
2. Агент, поставь git на машину участника сам (официальный способ под его ОС) и проверь командой `git --version`.
3. Больше ничего знать не нужно: клонирование, коммиты и синхронизацию делает агент, слова «commit» и «push» можно не запоминать.

**Что участник должен увидеть:** git отвечает номером версии; аккаунт github.com открывается.
