# Hermes: постоянный помощник

Hermes - открытый агент, который живет у тебя (на ноутбуке или сервере), помнит контекст, ведет твою базу и отвечает в Telegram через твоего бота. Это и есть Джарвис.

Агент, установку делаешь ты, участник смотрит:
1. Официальный источник: github.com/NousResearch/hermes-agent - найди в README актуальную команду установки под систему участника (Mac / Windows / Linux) и выполни ее, проговаривая шаги.
2. Первичная настройка: `hermes setup`. Главное правило всех экранов визарда, проговори участнику: **Enter выбирает строку, на которую указывает стрелка-курсор (->), а НЕ строку с отмеченной точкой (●)**. Сначала доведи стрелку до нужного пункта, потом жми Enter; промахнулся и попал не туда - ESC вернет назад. Экраны по порядку: (а) «How would you like to set up Hermes?» - выбираем **Full setup** (стрелкой вниз, Enter); Quick Setup (Nous Portal) не берем - уводит мимо нашего общего ключа. (б) «Select provider» - список из ~20 провайдеров, курсор стоит на Nous Portal: листай стрелкой до **OpenRouter (Pay-per-use API aggregator)**, обычно третья строка, Enter - и вставляй ключ. Остальные провайдеры не трогаем. (в) «Select default model» - выбирай **deepseek/deepseek-v4-pro**: умная и почти не тратит лимит; на сложные задачи Hermes переключится на модель посильнее по просьбе и вернется обратно. (г) «Select terminal backend» - **Local** (или «Keep current (local)»): команды выполняются на этой машине. Docker-вариант - изолированная песочница, хороший апгрейд безопасности после тренинга, если стоит Docker; сейчас не берем. (д) «Messaging Platforms» - длинный список мессенджеров: стрелкой вниз найди **Telegram**, отметь его Space, подтверди Enter (остальные не трогаем). Визард попросит токен бота - в этот момент создаем своего бота по ustanovka/tg-bot.md: агент предлагает ники, BotFather выдает токен, токен вставляем в визард. Если участник хочет разобраться с ботом позже - Enter без выбора, подключим после (`hermes setup` можно запускать повторно). (е) «Tools» - экран с галочками инструментов: дефолт нам подходит (важное - Skills, Memory, Cron включены; на них работают наши скиллы и ритуалы), ничего не переключай, просто Enter. (ж) выбор браузера - **Local Browser** (recommended, free): встроенный браузер без ключей; платные облачные варианты не берем. (з) генерация изображений - **OpenRouter (image)**: работает через тот же наш ключ (внутри Gemini Flash Image - недорого); варианты с OAuth и подписками не берем. (и) озвучка (TTS) - **Microsoft Edge TTS** (recommended, free): без ключей, русские голоса есть. Остальные экраны визарда - значения по умолчанию, если урок не говорит иного.
3. Подключи модель: провайдер openrouter + личный ключ участника (ustanovka/openrouter-klyuch.md).
4. Запусти Hermes и проверь: «привет» - ответил.
5. Дальше свяжем с Telegram: ustanovka/tg-bot.md.

**Что участник должен увидеть:** Hermes отвечает; на вопрос «какая модель у тебя?» называет модель без ошибок.

## Окно вместо терминала (по желанию)
У Hermes есть десктоп-приложение и веб-интерфейс: чат с Джарвисом и настройки в обычном окне, как в мессенджере - терминал больше не нужен. Агент, если участнику некомфортен терминал - найди в официальном README (github.com/NousResearch/hermes-agent) актуальный способ поставить десктоп-приложение или поднять веб-интерфейс, настрой и покажи участнику. Дальше он живет в окне и в Telegram.

Важно знать:
- Джарвис на ноутбуке живет, пока ноутбук не спит. Закрыл крышку - Джарвис уснул, бот в телефоне замолчал. Постоянный вариант - на VPS (ustanovka/vps.md): он не спит никогда.
- В интернет локальный Hermes ходит с твоего компьютера. Если Telegram у тебя работает только при включенном VPN - держи VPN включенным, иначе связка с твоим ботом не достучится. На VPS этой зависимости нет.
- Настройки подхватываются при перезапуске: поменял конфиг - перезапусти Hermes.
