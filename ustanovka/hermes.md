# Hermes: постоянный помощник

Hermes - открытый агент, который живет у тебя (на ноутбуке или сервере), помнит контекст, ведет твою базу и отвечает в Telegram через твоего бота. Это и есть Джарвис.

Агент, установку делаешь ты, участник смотрит:
1. Официальный источник: github.com/NousResearch/hermes-agent - найди в README актуальную команду установки под систему участника (Mac / Windows / Linux) и выполни ее, проговаривая шаги.
2. Первичная настройка: `hermes setup`. Перед стартом проговори участнику правило экранов визарда - они бывают ДВУХ типов, и Enter в них работает по-разному:
   - **Выбор одного пункта** (кружки ● / ○): стрелками доведи курсор-стрелку до нужной строки и жми Enter. Enter выбирает то, где СТРЕЛКА, а не то, где отмечена точка.
   - **Выбор нескольких** (квадратные скобки [ ]): **пробел ставит галочку [✓]**, Enter подтверждает весь список разом. Enter без пробела = пустой выбор, шаг молча пропущен.
   Промахнулся - ESC возвращает назад. Экраны по порядку: (а) «How would you like to set up Hermes?» - выбираем **Full setup** (стрелкой вниз, Enter); Quick Setup (Nous Portal) не берем - уводит мимо нашего общего ключа. (б) «Select provider» - список из ~20 провайдеров, курсор стоит на Nous Portal: листай стрелкой до **OpenRouter (Pay-per-use API aggregator)**, обычно третья строка, Enter - и вставляй ключ. Остальные провайдеры не трогаем. (в) «Select default model» - выбирай **deepseek/deepseek-v4-pro**: умная и почти не тратит лимит; на сложные задачи Hermes переключится на модель посильнее по просьбе и вернется обратно. (г) «Select terminal backend» - **Local** (или «Keep current (local)»): команды выполняются на этой машине. Docker-вариант - изолированная песочница, хороший апгрейд безопасности после тренинга, если стоит Docker; сейчас не берем. (д) «Messaging Platforms» - жми Enter, НЕ выбирая ничего: Telegram надежнее подключить после визарда отдельной командой (см. «Доводка» ниже). Ловушка экрана: отметка ставится пробелом, Enter без Space = пусто - половина зала проскочит, поэтому и выносим отдельно. (е) «Tools» - экран с галочками: проверь, что включены Skills, Memory, Cron (на них наши скиллы и ритуалы), и **сними галочку с Computer Use** - на тренинге он не нужен, а тянет установку отдельного приложения и системные разрешения macOS. Остальное по дефолту, Enter. (ж) выбор браузера - **Local Browser** (recommended, free): встроенный браузер без ключей; платные облачные варианты не берем. (з) генерация изображений - **OpenRouter (image)**: работает через тот же наш ключ (внутри Gemini Flash Image - недорого); варианты с OAuth и подписками не берем. (и) озвучка (TTS) - **Microsoft Edge TTS** (recommended, free): без ключей, русские голоса есть. (к) поиск (Web Search) - на вопрос про Nous Portal login отвечай n (пропустить): встроенный бесплатный DuckDuckGo-скилл уже есть, а нормальный поиск подключим ключом Exa в доводке. Остальные экраны визарда - значения по умолчанию, если урок не говорит иного.
3. Подключи модель: провайдер openrouter + личный ключ участника (ustanovka/openrouter-klyuch.md).
4. Запусти Hermes и проверь: «привет» - ответил.
5. Дальше свяжем с Telegram: ustanovka/tg-bot.md.

**Что участник должен увидеть:** Hermes отвечает; на вопрос «какая модель у тебя?» называет модель без ошибок.

## Доводка после визарда (обязательные 3 шага)

1. **Telegram-бот:** `hermes setup gateway` -> стрелкой до Telegram -> **Space** (галочка!) -> Enter -> дальше по ustanovka/tg-bot.md (рекомендуемый путь - автоматический, по ссылке/QR). В конце визард спросит про allowlist (вставь свой ID), home channel (Y) и установку фоновым сервисом (Y - тогда гейтвей работает сам, окна не нужны).
2. **Распознавание голосовух:** `hermes setup tools` -> Speech-to-Text -> Local Whisper (бесплатно, локально). Без этого голосовые сообщения твоему боту не распознаются - а диктовка голосом в бота у нас ключевой сценарий.
3. **Поиск через Exa:** ключ из ustanovka/exa.md добавь строкой `EXA_API_KEY=...` в файл `~/.hermes/.env` и перезапусти Hermes - агент получит нормальный веб-поиск.

Проверка здоровья в любой момент: `hermes doctor`.

## Окно вместо терминала (по желанию)
У Hermes есть десктоп-приложение и веб-интерфейс: чат с Джарвисом и настройки в обычном окне, как в мессенджере - терминал больше не нужен. Агент, если участнику некомфортен терминал - найди в официальном README (github.com/NousResearch/hermes-agent) актуальный способ поставить десктоп-приложение или поднять веб-интерфейс, настрой и покажи участнику. Дальше он живет в окне и в Telegram.

Важно знать:
- Джарвис на ноутбуке живет, пока ноутбук не спит. Закрыл крышку - Джарвис уснул, бот в телефоне замолчал. Постоянный вариант - на VPS (ustanovka/vps.md): он не спит никогда.
- В интернет локальный Hermes ходит с твоего компьютера. Если Telegram у тебя работает только при включенном VPN - держи VPN включенным, иначе связка с твоим ботом не достучится. На VPS этой зависимости нет.
- Настройки подхватываются при перезапуске: поменял конфиг - перезапусти Hermes.
