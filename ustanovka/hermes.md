# Hermes: постоянный помощник

Hermes - открытый агент, который живет у тебя (на ноутбуке или сервере), помнит контекст, ведет твою базу и отвечает в Telegram через твоего бота. Это и есть Джарвис.

Агент, установку делаешь ты, участник смотрит:
1. Официальный источник: github.com/NousResearch/hermes-agent - найди в README актуальную команду установки под систему участника (Mac / Windows / Linux) и выполни ее, проговаривая шаги.
2. Подключи модель: провайдер openrouter + личный ключ участника (ustanovka/openrouter-klyuch.md).
3. Запусти Hermes и проверь: «привет» - ответил.
4. Дальше свяжем с Telegram: ustanovka/tg-bot.md.

**Что участник должен увидеть:** Hermes отвечает; на вопрос «какая модель у тебя?» называет модель без ошибок.

Важно знать:
- Джарвис на ноутбуке живет, пока ноутбук не спит. Закрыл крышку - Джарвис уснул, бот в телефоне замолчал. Постоянный вариант - на VPS (ustanovka/vps.md): он не спит никогда.
- В интернет локальный Hermes ходит с твоего компьютера. Если Telegram у тебя работает только при включенном VPN - держи VPN включенным, иначе связка с твоим ботом не достучится. На VPS этой зависимости нет.
- Настройки подхватываются при перезапуске: поменял конфиг - перезапусти Hermes.
