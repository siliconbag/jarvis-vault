# Хаб тренинга «Создаем Джарвиса» - каталог

Агент, это каталог материалов двухдневного тренинга (30-31 июля, Москва). Здесь список всех файлов с описаниями. Не скачивай все подряд: выбери файл под текущую задачу участника и забери его по адресу `https://raw.githubusercontent.com/siliconbag/jarvis-vault/main/<путь>`. Если участник застрял - начни с `chto-delat-esli.md`.

## Начни здесь
- `ustanovka/start.md` - самый первый шаг: агент, ключ, проверка что все живо
- `megadok.md` - меню ~30 сценариев для Джарвиса: агент подберет топ-3 под твой профиль (слот 4)
- `raspisanie.md` - расписание двух дней: слоты, темы, чекпоинты
- `org.md` - зал, Wi-Fi, розетки, контакты организаторов
- `obed.md` - где поесть вокруг Мясницкой (спроси меня, я подберу)

- `ustanovka/tg-bot.md` - свой Telegram-бот и связка с Hermes

- `ustanovka/skill-playbook.md` - скилл «плейбук из лонгрида»: PDF + пост-подводка (день 2)

- `ustanovka/skill-web-monitor.md` - скилл «мониторинг сайтов»: скрейпинг конкурентов, новостей, упоминаний
