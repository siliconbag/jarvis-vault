### Obsidian Git

> [!Link]   **Ссылка на репозиторий** 
> https://github.com/Vinzent03/obsidian-git


> [!Notes]  **Описание** 
> Синхронизирует хранилище с репозиторием на GitHub кнопкой, без терминала. Умеет автокоммит по расписанию, ручной коммит с сообщением, просмотр истории изменений и откат.


> [!Connect]  **Фишки** и особенности использования
> Ключевой плагин для связки «волт на ноутбуке - волт на сервере»: агент на сервере читает ту же базу через git. Настройки на первый день: интервал автокоммита выключить, коммитить руками кнопкой - так понятнее, что происходит. Список исключений держим в `.gitignore` волта.
