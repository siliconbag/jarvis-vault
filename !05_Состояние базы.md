# Состояние базы

Страница-диагностика. Открывайте раз в неделю: она показывает, где база начала расползаться. Подробно про уборку - [[obsidian-plaginy]].

## Заметки-сироты

Ни одной ссылки ни туда, ни оттуда. Либо связать с темой, либо в архив.

```dataview
list
from ""
where length(file.inlinks) = 0 and length(file.outlinks) = 0 and !contains(file.path, "shablony") and !contains(file.path, "archive")
sort file.name asc
```

## Заметки без тегов

```dataview
list
from ""
where length(file.tags) = 0 and !contains(file.path, "archive")
sort file.mtime desc
limit 30
```

## Оборванные ссылки

Ссылки, которые ведут на несуществующие заметки. Либо создать заметку, либо убрать ссылку.

```dataviewjs
let d = {};
function process(k, v) {
  Object.keys(v).forEach(function (x) {
    x = dv.fileLink(x);
    if (d[x] == undefined) { d[x] = []; }
    d[x].push(dv.fileLink(k));
  });
}
Object.entries(dv.app.metadataCache.unresolvedLinks)
  .filter(([k, v]) => Object.keys(v).length)
  .forEach(([k, v]) => process(k, v));
dv.table(["Не существует", "Ссылаются из"],
  Object.entries(d).sort((a, b) => b[1].length - a[1].length)
    .map(([k, v]) => [k, v.join(" • ")]));
```

## Все теги в базе

```dataview
TABLE length(rows.file.name) as "заметок"
FROM ""
flatten file.tags as tag
group by tag
sort length(rows.file.name) desc
```

## Что менялось за неделю

```dataview
table file.mtime as "изменено"
from ""
where file.mtime > (date(now) - dur(7 days))
sort file.mtime desc
limit 30
```
