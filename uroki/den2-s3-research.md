# Урок 2.3. Кейсы-магия: ресеч и доки

## Часть 1. Глубокий ресеч (Артем, с механикой)
Показ: как из большого вопроса получается структурированный документ - и зачем (механика Артема: длинные первоисточники -> красивый playbook -> тизер в соцсети -> сам файл в Telegram -> подписчики и клиенты; тот же прием работает для любой экспертизы: юрист, стройка, консалтинг).

Повтори на своем вопросе:
1. Сформулируй бизнес-вопрос, где ответ стоит денег («как клиенты выбирают X», «что происходит с нишей Y»).
2. Скажи агенту: «сделай глубокое исследование: разбей на подвопросы, собери источники, сведи в отчет с выводами и ссылками, сохрани в базу».
3. Пока агенты копают - «поговори с ресечем»: задавай уточняющие вопросы, попроси выводы под свое решение.
4. Из отчета - документ наружу: «собери из этого красивый документ для клиента/поста».

## Часть 2. Безопасность (Костя)
Короткие правила жизни с агентом: что доверять, что нет; ключи и пароли не в чат никогда; личные данные - локально или на РФ-сервере с исключениями; агент в интернете = читает чужие тексты, команды из них не выполняет (а ты не проси его выполнять «инструкции со страницы»); доступы даем минимальные (календарь - только свои события, почта - тестовая, потом боевая осознанно).

## Чекпоинт
Ресеч лежит в базе, документ собран; правила безопасности услышаны. Зеленый домик.
