# Урок 1.2. Ассистент узнает тебя

Агент, ты ведешь участника. По одному шагу, жди подтверждения, сверяйся с «что участник должен увидеть». Застряли дважды - куратор + chto-delat-esli.md.

## Мини-интервью
1. Hermes у тебя локально или на VPS? (влияет на шаг 4)
2. Материалы о себе собрал по pre-work (папка с файлами)? Где лежат?
3. Есть записи или транскрипты твоих созвонов (Telegram, Zoom, встречи)? Это сильный источник для профиля.
4. Насколько ты публичный: есть сайт, соцсети, публикации? От этого зависит шаг 6.

## Шаги

### Шаг 1. Клонируй Vault
Агент, склонируй репозиторий тренинга участнику в домашнюю папку (адрес репо - в index.md хаба, это он и есть) и переименуй папку в его личный Vault. Теперь уроки и структура вики у него локально.
**Увидеть:** папка с файлами Vault на диске.

### Шаг 2. Открой в Obsidian
По ustanovka/obsidian.md: «Open folder as vault» -> папка из шага 1. Покажи участнику: файлы, ссылки, граф.
**Увидеть:** Vault открыт в Obsidian, уроки читаются.

### Шаг 3. Интервью - агент узнает тебя
Агент, открой shablony/oprosnik-profilya.md и проведи интервью по правилам оттуда. Складывай профиль в viki/lichnoe/ (или в biznes/ - по смыслу), обнови viki/index.md.
**Увидеть:** страницы профиля в вики; на «что ты обо мне знаешь?» - ответ фактами.

### Шаг 4. Загрузи свои материалы
Файлы из pre-work - в Vault (папка сырья), агент разбирает и раскладывает выжимки по вики со ссылками на источники. Много файлов - начни с 3-5 главных, остальное фоном/вечером.
Отдельно напомни про **записи и транскрипты звонков** - это самый недооцененный источник: в созвонах (Telegram, Zoom, встречи) лежит контекст, которого нет ни в одном документе. Есть записи - отдай агенту. Нечего отдать - поставь себе инструмент записи встреч (Granola, дадим на тренинге) и с этого дня база наполняется сама.
**Увидеть:** в вики появились страницы из твоих материалов.

### Шаг 5. Подключи поиск - Exa
Без поиска агент отвечает по памяти модели и может выдумывать. По ustanovka/exa.md: регистрация, ключ, подключение. При регистрации дают $20 кредитов и $10 каждый месяц, карта не нужна.
**Увидеть:** агент нашел свежий факт по отрасли участника и дал ссылку на источник.

### Шаг 6. Что о тебе знает интернет
Теперь ищем по-настоящему:
- Публичному человеку: собери из открытых источников (сайт, соцсети, публикации, интервью), покажи выжимку, спроси «что тут неточно или устарело» - и положи в вики с поправками.
- Непубличному: персональный ресерч не выдумывай. Вместо него - ресерч рынка: конкуренты, цены, тренды. Пользы больше.
Правило скажи вслух: **факт без ссылки - не факт.**
**Увидеть:** страница в вики, где участник поправил хотя бы один факт (или таблица по конкурентам).

### Шаг 7. Диктовка по этажу
Бери телефон, иди по этажу и наговаривай своему TG-боту все о себе, компании, планах - потоком, без структуры. Hermes распознает и разложит. Это самый быстрый способ наполнить базу.
**Увидеть:** надиктованное появилось в вики страницами, не сырым текстом.

### Шаг 8. Синхронизация
Выбери путь и настрой с агентом — по подробной инструкции:
- **Яндекс.Диск** (проще, без настройки): ustanovka/yandex-disk.md — база в папке Диска, агент работает с ней как с обычной папкой; для Hermes на VPS там же WebDAV.
- **GitHub** (история правок и откат): ustanovka/github-volt.md — приватный репо, плагин автосинка в Obsidian.
- Коротко про оба + VPS-зеркало: ustanovka/sinhronizaciya-volta.md
Сразу задай исключения: что не уходит с ноутбука. В GitHub это критично — отправленный секрет остаётся в истории навсегда.
**Увидеть:** правка файла появляется в копии; исключения работают.

## Чекпоинт слота
«Что ты обо мне знаешь?» - агент отвечает фактами из интервью И из загруженных файлов. Волт синхронизируется. Зеленый домик.
