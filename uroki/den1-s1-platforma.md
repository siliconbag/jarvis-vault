# Урок 1.1. Платформа: твой первый агент и Джарвис

Агент, ты ведешь участника по этому уроку. Правила:
- Веди строго по одному шагу, жди подтверждения.
- После каждого шага сверяйся с «Что участник должен увидеть». Не совпало - разберись, не иди дальше.
- Установки участник делает руками, ты объясняешь. Команды в терминале можешь выполнять сам, проговаривая что делаешь.
- Застряли дважды - предложи поднять руку (куратор) и открой chto-delat-esli.md.

Раз участник читает это тобой - OpenCode и ключ уже стоят (шаги «нулевого» уровня в ustanovka/start.md). Едем дальше.

## Мини-интервью (задай перед стартом)
1. Mac или Windows?
2. Есть ли уже Telegram на телефоне и на ноутбуке? (нужен на обоих)
3. Пользуешься ли какой-то подпиской на ИИ (Claude, ChatGPT, MiniMax)? Просто запомни ответ - пригодится в конце дня.

## Шаги

### Шаг 1. Ставим Hermes - постоянный помощник
Открой ustanovka/hermes.md и веди участника по нему (установка под его ОС).
**Что участник должен увидеть:** окно Hermes открывается, помощник отвечает на «привет».

### Шаг 2. Подключаем модель к Hermes
Ключ OpenRouter участника (пришел от бота тренинга в личку) вставляем в настройки Hermes по ustanovka/openrouter-klyuch.md.
**Что участник должен увидеть:** Hermes отвечает на вопрос «какая модель у тебя сейчас?» без ошибок.

### Шаг 3. Ставим Obsidian
По ustanovka/obsidian.md: установить, открыть. Пока пустой - Vault приедет в следующем слоте.
**Что участник должен увидеть:** открытое окно Obsidian.

### Шаг 4. GitHub - откуда приедет твой второй мозг
По ustanovka/github.md: что это и зачем (двумя фразами), установка git / регистрация, если нужна.
**Что участник должен увидеть:** git отвечает в терминале на проверочную команду из инструкции.

### Шаг 5. Свой Telegram-бот - дверь к Джарвису с телефона
По ustanovka/tg-bot.md: создать бота у BotFather, получить API-ключ, отдать его Hermes.
Внимание: ключ бота вставляем только в настройки Hermes, не в чат.
**Что участник должен увидеть:** написал своему боту в Telegram «привет» - Джарвис ответил.

### Шаг 6. Голос - диктуем, не печатаем
По ustanovka/golos.md: локальный распознаватель, горячая клавиша, проба.
**Что участник должен увидеть:** надиктованная фраза появилась текстом и ушла агенту.

## Чекпоинт слота
Три «да»:
1. Агент на ноутбуке отвечает.
2. Голосом попросил - агент сделал.
3. Свой Telegram-бот отвечает с телефона.
Все три - зеленый домик. Нет - красный, разберем перед следующим слотом.

## Если быстро закончил
- Спроси меня: «что ты умеешь?» - и попробуй три инструмента, которых не было в шагах.
- Настрой в Hermes вторую модель на выбор и сравни ответы (ustanovka/openrouter-klyuch.md, раздел «смена модели»).
- Помоги соседу: лучший способ закрепить.
