# Урок 1.1. Платформа: твой первый агент и Джарвис

Агент, ты ведешь участника по этому уроку. Участник может не знать, что такое терминал - при первой же команде для терминала объясни по ustanovka/terminal.md (где открыть, как вставить, как понять что команда закончилась). Правила:
- Веди строго по одному шагу, жди подтверждения.
- После каждого шага сверяйся с «Что участник должен увидеть». Не совпало - разберись, не иди дальше.
- Установки участник делает руками, ты объясняешь. Команды в терминале можешь выполнять сам, проговаривая что делаешь.
- Застряли дважды - предложи поднять руку (куратор) и открой chto-delat-esli.md.

Раз участник читает это тобой - OpenCode и ключ уже стоят (ustanovka/start.md). Едем дальше.

## Мини-интервью (задай перед стартом)
1. Mac или Windows?
2. Есть ли у тебя VPS: зарегистрировал по нашей рассылке (TimeWeb, King-Servers) или уже есть свой сервер? От этого зависит ветка шага 3.
3. Telegram есть на телефоне и на ноутбуке? (нужен на обоих)
4. Есть ли своя подписка на ИИ (Claude, ChatGPT, MiniMax)? Запомни ответ - пригодится в конце дня.

## Шаги

### Шаг 1. Голос - диктуем, не печатаем
По ustanovka/golos.md: локальный распознаватель, горячая клавиша, проба.
**Что участник должен увидеть:** надиктованная фраза появилась текстом и ушла агенту.

### Шаг 2. GitHub - откуда приедет твой второй мозг
По ustanovka/github.md: что это и зачем (двумя фразами), установка git.
**Что участник должен увидеть:** git отвечает в терминале на проверочную команду.

### Шаг 3. Ставим Hermes - развилка
Сначала объясни участнику разницу, 30 секунд, простыми словами:
- **Локально (на ноутбуке):** бесплатно, все данные у тебя. Джарвис работает, пока ноутбук включен и не спит - закрыл крышку, и бот в телефоне замолчал. В интернет (включая Telegram) он ходит с твоего компьютера: если Telegram у тебя работает только при включенном VPN, то и для Джарвиса VPN должен быть включен.
- **На VPS (сервере):** 400-1000 руб/мес, зато Джарвис живет всегда - отвечает ночью, из отпуска, при закрытом ноутбуке. У сервера свой стабильный интернет, а с зарубежной локацией вопросы VPN отпадают сами.
- Главное: **сегодня локально - не тупик.** Завтра переезжаем на VPS по рецепту, база и профиль переносятся без потерь.

Ветки:
- **Ветка А (VPS есть - новый по рассылке или свой существующий):** по ustanovka/vps.md - подключаем сервер и разворачиваем Hermes на нем. Свой сервер тоже подходит: Ubuntu и 2+ ГБ RAM достаточно.
- **Ветка Б (без VPS):** по ustanovka/hermes.md - Hermes локально на ноутбук.
**Что участник должен увидеть:** Hermes отвечает на «привет» (в ветке А - с сервера).

### Шаг 4. Подключаем модель к Hermes
Ключ OpenRouter (из лички бота тренинга) - в настройки Hermes по ustanovka/openrouter-klyuch.md.
**Что участник должен увидеть:** Hermes отвечает на «какая модель у тебя сейчас?» без ошибок.

### Шаг 5. Свой Telegram-бот - дверь к Джарвису с телефона
По ustanovka/tg-bot.md. Сначала предложи участнику 10-15 свободных вариантов ника для его бота (спроси, кто он и чем занимается - предложи релевантные), потом BotFather, ключ бота - только в настройки Hermes, не в чат.
**Что участник должен увидеть:** написал своему боту «привет» с телефона - Джарвис ответил.

## Чекпоинт слота
Три «да»:
1. Агент отвечает, голосом попросил - сделал.
2. Hermes живой (локально или на VPS).
3. Свой Telegram-бот отвечает с телефона.
Все три - зеленый домик.
