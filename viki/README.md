# Вики: твой второй мозг

Здесь живут знания, которые ведет агент. Ты кормишь его сырьем (голос, файлы, ссылки) - он раскладывает по страницам, связывает ссылками и держит актуальным.

## Как устроено
- `index.md` - каталог всех страниц (агент обновляет при каждом изменении).
- `log.md` - журнал: что и когда агент делал с базой.
- Папки-домены: `biznes/` (компания, клиенты, процессы), `lyudi/` (люди и контакты), `proekty/` (активные проекты), `idei/` (идеи и гипотезы), `lichnoe/` (цели, здоровье, личное).
- `_shablon-stranicy.md` - формат страницы.

## Правила (для агента)
1. Одна страница = одна сущность/тема. Не дублируй: новое о том же - обновляй существующую страницу.
2. У каждой страницы - строка summary в начале и ссылки на связанные страницы.
3. Источник не переписывай: сырье лежит отдельно, вики - выжимка со ссылкой на источник.
4. После изменений обнови index.md и добавь строку в log.md.
5. Раз в неделю предложи ревизию: сироты, битые ссылки, противоречия, устаревшее.
